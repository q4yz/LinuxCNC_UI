# HAL tools

## HAL pins and the oscilloscope (Debug page)

The pin list shows every HAL pin with its live value, filtered by name and direction. Select
up to 16 pins for the **oscilloscope**: run / stop, single shot, sample rate, time/div,
trigger (source, edge, level, mode, position), per channel V/div, shift, colour and
auto-scale.

The oscilloscope's settings and channels stay when you leave the Debug page; only the recorded
samples start again.

## Visual HAL editor

The **HAL Editor** page draws components and signals of the running HAL as a graph.
